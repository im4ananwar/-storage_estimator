\# Storage Estimator



\## Purpose

This Python program converts storage from gigabytes (GB) into megabytes (MB), kilobytes (KB), and bytes.



\## How to Run

1\. Install Python.

2\. Open a terminal in the project folder.

3\. Run the command:



&#x20;  `py storage\_estimator.py`



4\. Enter the storage amount in GB when prompted.



\## Example Input/Output



\*\*Input:\*\*

```text

Enter storage in GB: 1

```



\*\*Output:\*\*

```text

\--- Storage Estimator Results ---

Storage in MB: 1024.0

Storage in KB: 1048576.0

Storage in bytes: 1073741824

```
